Turkish decision model

Decision models answer typed questions about a text (for example, which team should handle a ticket, how urgent it is or whether a human should take over) and return a probability for every option instead of generated text. Existing decision models were developed for English, and their accuracy on Turkish is limited. Pusula is Decision 3.0 adapted to Turkish.

How it works

A request consists of a text (state) and named questions. The options of each question are defined in the request itself, so new labels can be introduced without retraining.

Request

{
  "state": "Kartımdan bilgim dışında 4.500 TL çekilmiş, hemen bloke edin!",
  "questions": {
    "ekip": {
      "type": "choice",
      "instructions": "Bu talebi hangi ekip ele almalı?",
      "criteria": {
        "dolandiricilik": "Şüpheli işlem ve dolandırıcılık",
        "kart_islemleri": "Kart başvurusu, limit ve şifre",
        "genel_destek": "Diğer sorular"
      }
    },
    "acil": { "type": "noul", "instructions": "Hemen müdahale gerekiyor mu?" },
    "risk": {
      "type": "score",
      "instructions": "Finansal risk ne düzeyde?",
      "criteria": ["Düşük", "Orta", "Yüksek"]
    }
  }
}

Answer (illustrative values)

  "answers": {

      "probabilities": {"dolandiricilik": 0.94, "kart_islemleri": 0.05, "genel_destek": 0.01},
      "confidence": 0.94
    },

      "confidence": 0.88,

    }
  },
  "model": "pusula"
}

Features

Pusula preserves the interface of Decision 3.0 and extends it for Turkish text.

Turkish first

Decision 3.0 has been fine-tuned on Turkish decision data from 20 domains, including banking, law, health, e-commerce, logistics and public services. Informal writing, typos, missing Turkish characters and mixed Turkish–English text are covered.

Options defined at request time

Questions and their options are specified in each request. The model is not limited to a fixed label set.

Three question types

choice (one option), noul (yes/no) and score (ordered levels). Every answer carries a probability for each option.

Drop-in d3 replacement

The request and answer format of the /v1/systemone endpoint of Decision 3.0 is preserved, so Pusula can replace d3 in existing integrations.

Built-in Turkish taxonomy

20 domains, 86 subdomains and 299 intents are provided, together with six universal checks: urgency, action required, human handoff, security risk, emotion and personal data.

Independent evaluation

Pusula has been evaluated against the base Decision 3.0 model on independently labeled Turkish test sets. The Turkish Decision Benchmark is published with the model.

Two models are provided. Both accept identical requests.

Quick start

A CUDA build of PyTorch should be installed beforehand. Pusula Nano requires only the serve extra and runs on CPU.

Installation

pip install "pusula[serve,d3] @ git+https://github.com/hsnsahinhsn/pusula"
hf download vllm-sr/d3 --local-dir ~/d3 --exclude "assets/*"     # base Decision 3.0 weights (~52 GB)
hf download hsnsahinhsn/pusula --local-dir ~/pusula                # Pusula adapter (~0.9 GB)
# or the small model, which needs no base weights:
hf download hsnsahinhsn/pusula-nano --local-dir ~/pusula-nano      # Pusula Nano (~0.6 GB)

Python

from pusula.inference import D3Engine, DecisionEngine

engine = D3Engine.load("~/d3", adapter="~/pusula")      # Pusula (Turkish Decision 3.0)
# engine = DecisionEngine.load("~/pusula-nano")          # Pusula Nano (GPU or CPU)

answers = engine.decide(
    "Siparişim 5 gündür kargoda, hâlâ gelmedi. Artık iptal etmek istiyorum.",
    {
        "niyet": {
            "type": "choice",
            "instructions": "Müşteri ne istiyor?",
            "criteria": {
                "kargo_takip": "Gönderinin nerede olduğunu öğrenmek",
                "iptal": "Siparişi iptal etmek",
                "iade": "Teslim alınan ürünü iade etmek",
            },
        },
        "temsilci": {"type": "noul", "instructions": "Bir insan temsilciye aktarılmalı mı?"},
    },
)
print(answers["niyet"]["choice"], answers["niyet"]["confidence"])

The HTTP API, the built-in taxonomy, guidance on writing questions and the use of confidence values are documented in the README.

Training your own model

All components used to build Pusula are included in the repository, so Decision 3.0 can be fine-tuned on data from other domains or languages. Labeled decision data is generated with a local open-weight model, cleaned and used to fine-tune d3 with QLoRA. Each stage can be resumed.
